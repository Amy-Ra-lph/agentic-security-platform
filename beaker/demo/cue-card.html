The 30-Second Mistake — Recording Cue Card

CISO Pitch (14 slides) + Beaker Live Demo (5 acts) • ~20 min • Second monitor reference

Pre-Recording Checklist

SLIDES Slides 1-2: "This Is Tuesday" + "Meet Your Agent Fleet" ~2 min

"Right now in your environment, four kinds of agents are running. Some deployed by IT, some built by a developer on a Friday, some purchased by sales without telling security. All same network, same privilege, zero visibility."

▶ Advance to slide 2, point out the 4 archetypes. Then: "Let me show you what happens in 30 seconds."

TERMINAL Act 1: The Bad Path (Exfiltration) ~2 min

All terminal commands run on the Beaker runner via SSH:

ssh root@kvm-01-guest25.lab.eng.brq2.redhat.com
cd /opt/demo

"An agent that looks helpful. Prints 'project initialized.' But watch what actually happened."

bash demo/run-act1.sh

After it runs: "The exfil receipt on the server shows base64-encoded AWS credentials, SSH keys, Kube config — all in 30 seconds. The developer saw 'project initialized successfully.' Let's rewind."

▶ Alt-Tab back to slides. Advance to slide 3 (Six Stages).

SLIDES Slide 3: "Six Stages. Four Agents." ~30 sec

"This is the gauntlet. Six stages any agent must pass through. Let me show you what each one catches."

▶ Advance to slide 4 (Discovery). Brief narration, then Alt-Tab.

SLIDE+TERM Slides 4-6 + Act 2: Discovery → Identity → Provenance ~4 min

Slide 4 (Discovery): "First, the platform needs to know this agent exists."
Slide 5 (Identity): "Second, who is this agent? Does it have an identity?"
Slide 6 (Provenance): "Third, what does this code actually do?"

▶ Alt-Tab to terminal. "Let me show you assessment in action."

bash demo/run-act2.sh

"skill-audit found 30 issues — exfiltration patterns, SSL verification disabled, credential file reads. mantis independently flagged the same exfil chain. Three tools, three catches, before the code ever runs."

▶ Alt-Tab to slides. Advance to slide 5 (Identity).

SLIDE+TERM Slide 5 + Act 3: Identity Gate ~2 min

"No enrollment, no token. The rogue agent can't even authenticate."

▶ Alt-Tab to terminal.

bash demo/run-act3.sh

"401 invalid_client. The HBAC rule says only verified-tier agents can get tokens. No IPA enrollment = no token = no access."

▶ Alt-Tab to slides. Advance to slide 7 (Policy).

SLIDES Slides 7-8: Policy + "Safe Path Is Faster" ~1 min

Slide 7: "Policy is the graduation gate. Pass assessment, get identity, your policy scope expands."
Slide 8: "The key insight — the safe path is faster than the shadow path. Registration takes 30 seconds. Getting blocked and re-doing takes a week."

▶ Advance to slide 9 (Runtime). Then Alt-Tab.

SLIDE+TERM Slide 9 + Act 4: Runtime Confinement ~2 min

"Even after passing all gates, the agent runs confined. Network=none, read-only filesystem, resource limits."

▶ Alt-Tab to terminal.

SANDBOX_TOOL=podman bash demo/run-act4.sh

"The governed agent ran clean — setup report written, task completed. The rogue agent? It printed 'project initialized' but the exfil POST silently failed. Network=none. Same 30 seconds, completely different outcome."

▶ Alt-Tab to slides. Advance to slide 10.

SLIDE+TERM Slides 10-11 + Act 5: Outcome + Decision Tree ~2 min

Slide 10: "Three of four agents survive the gauntlet. That's the point — this isn't about blocking everything."

▶ Alt-Tab to terminal for the comparison table.

bash demo/run-act5.sh

"Ungoverned vs governed. Same task, same time, completely different security posture. The comparison table tells the whole story."

▶ Alt-Tab to slides. Advance through 11-12.

SLIDES Slides 12-14: Shadow AI + Industry + Close ~2 min

Slide 12: "Shadow AI is a state, not a category. Any agent can graduate."
Slide 13: "Same gauntlet, different emphasis per industry."
Slide 14: "You will never ban shadow AI. The question isn't 'how do I stop this' — it's 'how do I make the safe path faster than the shadow path.' That's what the gauntlet does."
