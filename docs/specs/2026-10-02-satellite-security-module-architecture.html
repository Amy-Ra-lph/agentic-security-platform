Fast Path
Seconds — real-time event stream
1 SELinux / auditd / firewall / fapolicyd event
↓
2 rsyslog collects & forwards
↓
3 EDA rulebook matches event pattern
↓
4 Automated response (pre-approved)
↓
5 Event counts → Satellite dashboard
Slow Path
Minutes–hours — periodic compliance
1 Satellite schedules SCAP / AIDE scan
↓
2 Host runs scan, returns results
↓
3 Satellite indexes findings + drift
↓
4 Lightspeed generates remediation advice
↓
5 Ansible remediates (manual or auto)
IAM Path
Event-triggered — identity response
1 Fast-path event triggers identity rule
↓
2 EDA evaluates severity + threshold
↓
3 IdM / FreeIPA action (HBAC, suspend)
↓
4 ahdapa token revocation (if OAuth)
↓
5 Status reflected in Satellite
All paths converge ▼

Advice
Lightspeed On-Prem

Remediation
Ansible + EDA
  • Manual: Satellite launches playbook
  • Auto: EDA pre-approved rules
  • Post-remediation rescan confirms fix
  • Circuit breaker on repeated failures
  • IAM actions via IdM (not Satellite)
