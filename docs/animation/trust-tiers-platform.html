The Five Layers

L1 DARC — Credential issuance. Verifies who the agent is and how it enrolled. Sets confirmation requirements per tier.
L2 WID — Token lifecycle. Assigns scope ceiling based on agent's role profile. Enforces delegation narrowing (privileges never widen).
L3 Policy — Runtime authorization. Context-aware rules (time, severity, rate). Scopes are the ceiling; policy is the floor.
L4 Confinement — Two stacked mechanisms: OpenShell (namespace + syscall) and Blastwall (SELinux MAC + MLS/MCS). Either works alone; both together = defense in depth.
L5 Audit — Logging + response. Detects anomalies (policy violations AND permitted-but-wrong behavior). Triggers circuit breaker and revocation.

Four Trust Tiers

Blocked — Known-bad, post-revocation, compliance-restricted. Zero access — enrollment denied at L1. Example: MalBot.
Untrusted — Unknown third-party plugins. Read-only, OpenShell strict + Blastwall agent_untrusted_t, no delegation, full trace. Example: PluginX.
Verified — Known agents (Claude, Copilot) with device pairing. Scoped write, namespace isolation, code-verified. Example: DevAssist.
Sovereign — Internal agents on IPA-enrolled hosts. Full scopes, no OpenShell sandbox, Blastwall standard audit, platform-attested. Example: SOC Sentinel.
Key insight: Same endpoint, four outcomes. Agents graduate up with evidence, get demoted on breach. No per-agent config needed.
